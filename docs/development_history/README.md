# Development history document

This directory contains the beginner-oriented history of the substantive
changes made to the solar-car energy-management package.

- `solar_package_development_history.md`: GitHub-friendly source document.
- `solar_package_development_history.tex`: print-oriented Japanese source.
- `solar_package_development_history.pdf`: generated PDF.

The history intentionally omits routine confirmation, monitoring, and repeated
test commands. It records changes that altered source code, data contracts,
models, operation, safety gates, documentation, or release contents.
