# MLE hand-calculation workbook

- `mle_workbook_questions.pdf`: 問題編
- `mle_workbook_answer_sheet.pdf`: 解答用紙
- `mle_workbook_solutions.pdf`: 完全解答・解説編

実装と同じ順序で、入力品質判定、PV、battery、motion、11次元joint fit、map shape correction、終端anchor、day/segment別replay検証、profile反映を手計算する教材です。map形状補正はDay1--Day5で学習し、Day6をoptimizerから隔離した独立hold-outとして採否を決めます。scalar joint fit後のday別診断とは目的を区別します。
