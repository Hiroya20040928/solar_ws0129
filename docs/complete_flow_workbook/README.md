# Complete flow workbook

This directory contains three synchronized TeX/PDF documents:

- solar_mpc_complete_workbook_questions.pdf: question book.
- solar_mpc_complete_workbook_answer_sheet.pdf: separate answer sheet.
- solar_mpc_complete_workbook_solutions.pdf: worked solutions.

Compile with XeLaTeX twice from this directory. The question and solution books
share one body file, so equations and question numbers cannot drift apart.
