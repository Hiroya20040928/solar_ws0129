# Evidence Notes

## What to store here

- Why each map is trusted.
- Which experiment, vendor document, or official race note supports it.
- Which stops are regulation stops, trouble stops, or strategy stops.
- How the terminal SoC anchor was derived.

## Minimum expectation

- Grounded map provenance is written in `grounded_map_sources.yaml`.
- Actual race events are written in `actual_event_annotations.yaml`.
- Counterfactual edits are written in `counterfactual_no_trouble.yaml`.
- Terminal SoC evidence is written in `terminal_anchor.yaml`.
